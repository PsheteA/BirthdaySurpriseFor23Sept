HOW TO ADD MORE PHOTOS:
1. Put your additional photos in the photos folder.
2. Open index.html.
3. Replace any placeholder photo slot with:
   <img src="photos/photo3.jpg" alt="Our memory 3">
   and so on.

HOW TO ADD MUSIC:
1. Create a folder named music.
2. Put your MP3 inside as birthday-song.mp3.
3. In index.html, find the commented <source> line and remove the HTML comments around it.

HOW TO TEST:
Double-click index.html. It should open in Chrome.

HOW TO SEND AS A LINK:
Upload the whole birthday_surprise folder to any static website host such as GitHub Pages, Netlify, or Vercel. Upload the complete folder so the photos remain connected.
